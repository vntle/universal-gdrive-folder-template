## Why this template?

This structure is designed to:
- work for school, university, and postgraduate study
- support both domestic and international students
- separate study, life, work, media, travel, and admin clearly
- stay scalable over many years
- remain readable and easy to maintain

## Core principles

1. Organize by **function**, not just by file type.
2. Keep folder depth reasonable.
3. Use a **temp** folder for unsorted files.
4. Use an **archive** folder for old but important materials.
5. Use a consistent naming convention.
6. Review and clean regularly.

## Notes

- You do not need every folder; adapt the template to your own life.
- If you are a student, start with `01_SCHOOL_AND_STUDY`, `03_PERSONAL_DOCUMENTS`, `04_FINANCE_AND_ADMIN`, and `12_TEMP_UNSORTED`.
- If you create content, also use `06_PHOTOS_AND_VIDEOS`, `07_AUDIO_AND_MUSIC`, and `10_SOCIAL_MEDIA_AND_BRANDING`.
