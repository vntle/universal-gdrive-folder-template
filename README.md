# Universal Google Drive Folder Template

> **A clean, ready-to-use Google Drive folder structure** for students, researchers, international students, and anyone who wants a neatly organised digital life on cloud storage.

Created by **[Nhat Le Vo](https://github.com/vntle)** — Doctoral researcher in Germany.

---

## Who is this for?

This template was made to help **everyone who uses cloud storage** — especially:

- 🎓 **Students** at all levels: high school, undergraduate, postgraduate
- 🌍 **International students** navigating visas, housing, admin, and new countries
- 🔬 **Researchers and engineer** managing data, papers, and projects
- 🧑‍💻 **Professionals and creators** who need a clean place for work, media, and personal files
- 📦 **Anyone** whose files are scattered and chaotic

The goal is simple: give everyone a **neatly organised shelf** to store their digital data and things — so they can stop losing files and start focusing on what matters.

## How to use

### Step 1 — Download

1. Go to the top of this repository page on GitHub.
2. Click the green **`< > Code`** button.
3. Click **`Download ZIP`**.
4. Save the ZIP file to your computer.

### Step 2 — Unzip

- **Windows**: Right-click the ZIP file → `Extract All`
- **macOS**: Double-click the ZIP file
- **Linux**: Right-click → `Extract Here`

You will get a folder called `universal-gdrive-folder-template` with the full structure inside.

### Step 3 — Upload to Google Drive

1. Open [Google Drive](https://drive.google.com) in your browser.
2. Click **`+ New`** → **`Folder upload`**.
3. Select the unzipped folder from your computer.
4. Wait for the upload to finish.
5. You now have the full folder structure in your Google Drive. ✅

> **Tip:** You can also drag and drop the unzipped folder directly into your Google Drive browser window.

---

## Core principles

1. Organise by **function**, not by file type.
2. Keep folder depth to **2–3 levels** maximum.
3. Use **`12_TEMP_UNSORTED`** as your inbox for new files.
4. Use **`13_ARCHIVE`** for old files you want to keep but no longer use.
5. Use a **consistent naming convention** (see `99_SYSTEM_METADATA/Naming_Conventions.md`).
6. Review and clean up **regularly**.

## Recommended starter folders by user type

| User | Start with |
|------|------------|
| School student | `01_SCHOOL_AND_STUDY`, `03_PERSONAL_DOCUMENTS`, `12_TEMP_UNSORTED` |
| University student | All of the above + `02_WORK_AND_CAREER`, `04_FINANCE_AND_ADMIN` |
| International student | All of the above + `09_TRAVEL_AND_MOVING` (visa, housing, move) |
| Researcher | All of the above + `06_PHOTOS_AND_VIDEOS` (field work) |
| Creative / content creator | `06_PHOTOS_AND_VIDEOS`, `07_AUDIO_AND_MUSIC`, `10_SOCIAL_MEDIA_AND_BRANDING` |
| Everyone | `12_TEMP_UNSORTED` first — sort later |

## Naming convention

```text
YYYY-MM-DD-Category-Description-Version.ext
```

Examples:
- `2026-06-01-Exam-Physics-Revision-v1.pdf`
- `2025-10-12-Visa-Appointment-Germany.pdf`
- `2024-03-15-Portrait-Studio-v1.jpg`

See full rules in [`99_SYSTEM_METADATA/Naming_Conventions.md`](99_SYSTEM_METADATA/Naming_Conventions.md).
